# Бот продаж ADrenaline

AI-ассистент Даниила: берёт заявку с сайта, выходит на человека в Telegram или WhatsApp и записывает на 20-минутный звонок с Даниилом. Всё видно в группе «ADrenaline · Заявки».

## Как работает

1. Человек отправляет форму на сайте. Сайт (Cloudflare, `functions/api/lead.js`) передаёт заявку боту на `/api/lead` и показывает на «Дякую» кнопки «Обрати час у Telegram» и «…у WhatsApp».
2. В группу приходит карточка лида: имя, контакт, услуга, ниша, бюджет, ответы квиза, объявление. Кнопки: «Беру сам», «Написать через бота», «Не целевой».
3. Нажал кнопку Telegram или WhatsApp — бот здоровается, напоминает, что в заявке, и показывает свободные окна. Вопросы человека разбирает ИИ: отвечает по ценам и условиям с сайта, сам записывает по фразе вроде «завтра в 12 в Meet», зовёт Даниила, если вопрос нестандартный.
4. Не нажал за `TG_WAIT_MIN` минут (3) — бот пишет первым в WhatsApp утверждённым шаблоном на номер из формы. Ответил — дальше та же переписка с ИИ и выбором времени.
5. Нет WhatsApp, нет ответа за `NO_REPLY_MIN` минут (20) или в заявке только @ник — карточка «☎️ Позвонить вручную» в группу. Если включён голосовой ИИ (`VOICE_CALLS=1`) и есть номер — вместо карточки звонит агент ElevenLabs.
6. Записался — подтверждение клиенту (с ссылкой на Meet, если задан `MEET_URL`), событие в Google Calendar Даниила, запись в группу с кнопкой «Подтвердить». За 2 часа — напоминание клиенту и в группу.
7. Общался, но не записался — одно напоминание через `NUDGE_HOURS` (20 ч). Ночью бот первым не пишет (`CONTACT_HOURS`).
7а. Бот написал в чате, а человек молчит `SILENCE_CALL_MIN` минут (30) — звонок, один раз на лида и только в `CONTACT_HOURS`: если включён голосовой ИИ (`VOICE_CALLS=1`) и есть номер — звонит агент ElevenLabs; если голосового ИИ нет — карточка «☎️ Позвонить» в группу; если номера нет — бот просит оставить номер, а в группу уходит «номера нет — написать @ник». Оставил номер — «☎️ Позвонить». Стадия лида не меняется: ответит в чате — ИИ продолжит разговор.
8. «Беру сам» или ответ через бота — ИИ по этому лиду замолкает, дальше ведёт человек. Сообщения лида продолжают приходить в группу.

Человек может написать боту и сам, без формы (в Telegram или на WhatsApp-номер): тогда это новый лид с тем же сценарием. Бот честно представляется AI-ассистентом.

## Запуск на Railway

1. Новый сервис из этого репозитория (Dockerfile в корне). Volume, подключённый в `/srv/data` — там база SQLite.
2. Settings → Networking → Generate Domain: получится адрес вида `https://adrenaline-sales.up.railway.app`. Он нужен сайту и Meta.
3. Variables — ниже. После деплоя `https://<адрес>/health` должен отвечать `{"ok": true}`.

### Обязательные переменные

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен нового бота продаж из @BotFather (не демо-бота) |
| `ANTHROPIC_API_KEY` | ключ Claude |
| `SALES_CHAT_ID` | группа «ADrenaline · Заявки»: `-5567948118`. Бота продаж нужно добавить в группу |
| `SALES_STAFF_IDS` | `1080369588,7394861540,5169962273` — кто может жать кнопки в личке с ботом |
| `LEAD_API_SECRET` | длинная случайная строка; та же — в Cloudflare как `SALES_BOT_SECRET` |

### Необязательные

| Переменная | По умолчанию | Что это |
|---|---|---|
| `MEET_URL` | — | постоянная комната Google Meet Даниила |
| `CLAUDE_MODEL` | `claude-sonnet-4-5` | модель агента |
| `SALES_DAYS`, `SALES_HOURS`, `SALES_SLOT_MIN`, `CALL_MIN` | пн–пт, 10:00–19:00, 30, 20 | окна для звонков |
| `SALES_DAYS_AHEAD`, `SALES_MIN_LEAD_HOURS` | 7, 1 | на сколько дней вперёд и за сколько часов минимум |
| `TG_WAIT_MIN`, `NO_REPLY_MIN`, `NUDGE_HOURS` | 3, 20, 20 | тайминги автоматики |
| `SILENCE_CALL_MIN` | 30 | бот написал, человек молчит N минут → звонок (`0` — выключить) |
| `VOICE_CALLS` и `ELEVENLABS_*`, `VOICE_TOOL_SECRET` | `0` | голосовой ИИ, см. раздел ниже |
| `CONTACT_HOURS` | `09:00-20:00` | когда бот может писать первым |
| `AUTOMATION` | `1` | `0` — только ответы, без шаблонов и напоминаний |
| `AI_DAILY_LIMIT` | 40 | ответов ИИ одному лиду в сутки |
| `GA4_API_SECRET` | — | событие `call_booked` в GA4 к тому же посетителю сайта |
| `BOT_USERNAME` | берётся у Telegram | @ник бота для ссылок |

## Сайт (Cloudflare Pages)

Settings → Variables and secrets:

- `SALES_BOT_URL` — адрес бота на Railway;
- `SALES_BOT_SECRET` (secret) — то же значение, что `LEAD_API_SECRET`.

Пока переменных нет, форма работает как раньше. Если бот недоступен больше 4 секунд, заявка всё равно приходит в старый Telegram-чат.

## WhatsApp Cloud API (Meta)

1. business.facebook.com — бизнес-портфолио ADrenaline. developers.facebook.com → Create app → тип Business → добавить продукт WhatsApp.
2. WhatsApp → API Setup → добавить номер. Номер не должен быть зарегистрирован в обычном приложении WhatsApp (или его нужно оттуда удалить). Подтвердить по SMS или звонку. `Phone number ID` → `WA_PHONE_NUMBER_ID`, сам номер → `WA_NUMBER`.
3. Business settings → System users → создать системного пользователя (Admin), выдать доступ к приложению и аккаунту WhatsApp, сгенерировать постоянный токен с правами `whatsapp_business_messaging` и `whatsapp_business_management` → `WA_TOKEN`.
4. App settings → Basic → App secret → `WA_APP_SECRET`. Любая длинная строка → `WA_VERIFY_TOKEN`.
5. WhatsApp → Configuration → Webhook: URL `https://<адрес бота>/wa/webhook`, Verify token = `WA_VERIFY_TOKEN` → Verify and save. Подписаться на поле `messages`.
6. WhatsApp Manager → способ оплаты (первые сообщения по шаблону платные: ~$0.02–0.10 за сообщение).
7. Шаблон `lead_followup`, категория Utility, языки Ukrainian и Russian, переменная `{{1}}` = имя:
   - uk: «Вітаю, {{1}}! Ви залишили заявку на сайті ADrenaline. Даниїл розбере її на безкоштовному 20-хвилинному дзвінку. Відповідайте на це повідомлення — підберу зручний час.»
   - ru: «Здравствуйте, {{1}}! Вы оставили заявку на сайте ADrenaline. Даниил разберёт её на бесплатном 20-минутном звонке. Ответьте на это сообщение — подберу удобное время.»

   Если утверждён только украинский, укажите `WA_TEMPLATE_LANGS=uk:uk,ru:uk`.
8. Необязательно: шаблон напоминания (`{{1}}` имя, `{{2}}` время) → его имя в `WA_REMINDER_TEMPLATE`. Он нужен, когда человек молчал больше суток: обычное сообщение WhatsApp тогда не пропустит.

Пока `WA_TOKEN` и `WA_PHONE_NUMBER_ID` не заданы, канал выключен: остаётся кнопка Telegram, а кто её не нажал — получает карточку «позвонить вручную».

## Голосовой ИИ (ElevenLabs)

Когда пора звонить — человек молчит `SILENCE_CALL_MIN` минут после сообщения бота, оставил номер по просьбе бота, не ответил на WhatsApp или у него нет WhatsApp, — лиду звонит голосовой агент ElevenLabs через номер Zadarma. Агент уточняет запрос и записывает на звонок с Даниилом **через этого же бота**: окна, Google Calendar, напоминания и «Подтвердить» общие с чатом. Итог звонка с текстом разговора приходит ответом на карточку лида. Пока `VOICE_CALLS=0` или не заданы ключи — всегда карточка «☎️ Позвонить», как раньше.

| Переменная | Что это |
|---|---|
| `VOICE_CALLS` | `1` — звонит агент; `0` (по умолчанию) — карточка |
| `ELEVENLABS_API_KEY` | ключ API ElevenLabs (аккаунт компании) |
| `ELEVENLABS_AGENT_ID` | id агента «ADrenaline · обзвон заявок» (`agent_…` в адресе страницы агента) |
| `ELEVENLABS_PHONE_NUMBER_ID` | id номера Zadarma после импорта в ElevenLabs (Phone numbers) |
| `ELEVENLABS_WEBHOOK_SECRET` | секрет post-call webhook (показывается при создании вебхука) |
| `VOICE_TOOL_SECRET` | длинная случайная строка: заголовок `X-Tool-Secret` в инструментах агента |

Голос включается, только когда заданы **все** переменные: `VOICE_CALLS=1`, `ELEVENLABS_API_KEY`, `ELEVENLABS_AGENT_ID`, `ELEVENLABS_PHONE_NUMBER_ID`, `ELEVENLABS_WEBHOOK_SECRET`, `VOICE_TOOL_SECRET`. Если чего-то нет, бот пишет в лог, какой переменной не хватает, и ставит карточку «☎️ Позвонить».
| `VOICE_LANGUAGE_OVERRIDE` | `1` — лидам с `/ru` агент начинает по-русски, лидам с `lang=en` — по-английски (нужно разрешить Language в Security агента) |
| `VOICE_MAX_ATTEMPTS`, `VOICE_RETRY_MIN`, `VOICE_RESULT_TIMEOUT_MIN` | 2, 30, 20: звонок + один повтор через 30 мин; итог не пришёл за 20 мин — «не дозвонились» |

**Что видит команда в группе:** «🤖📞 Запущен AI-звонок» → «✅ Записался на звонок» (если записался) → «📞 Итог AI-звонка» с текстом разговора. Итоги: записался; ⏰ просит перезвонить / 🙋 нужен Даниил — карточка с «Беру сам»; не целевой; 🔕 «не звоните» — лид помечается и больше ничего не получает; 📵 не дозвонились — один повтор, потом «☎️ Позвонить вручную». Ночью агент не звонит. ElevenLabs недоступен — сразу карточка. Лид ответил в чате, пока ждал повтора, — повтор отменяется.

**Настройка агента ElevenLabs** (промпт, голос, поля итога — в документе «Голосовой агент ADrenaline — настройка ElevenLabs»):

- Инструмент `get_free_slots`: Webhook, `POST https://<адрес бота>/voice/tools/slots`, заголовок `X-Tool-Secret` = `VOICE_TOOL_SECRET` (секретом), тело: `lead_id` — **dynamic variable** `lead_id`.
- Инструмент `book_call`: `POST https://<адрес бота>/voice/tools/book`, тот же заголовок, тело: `lead_id` — dynamic variable `lead_id`, `datetime` — заполняет LLM («YYYY-MM-DDTHH:MM по Киеву, только из get_free_slots»).
- Post-call webhook: `https://<адрес бота>/voice/webhook`, HMAC; события transcription и call initiation failure. Секрет → `ELEVENLABS_WEBHOOK_SECRET`.

Агенту при звонке передаются dynamic variables `{{name}}`, `{{service}}`, `{{now}}`, `{{lead_id}}`, `{{chat}}` (последние сообщения переписки с ботом).

Языки агента: украинский (основной), русский и английский (Agent → Additional languages, у каждого своя первая фраза). Агент начинает по-украински и сам переходит на язык собеседника через системный инструмент `language_detection`.

## Google Calendar Даниила (необязательно)

Нужен, чтобы бот не предлагал время, занятое в календаре, и сам ставил событие звонка.

1. console.cloud.google.com → новый проект → APIs & Services → включить Google Calendar API.
2. IAM & Admin → Service accounts → создать → Keys → Add key → JSON. Содержимое файла одной строкой положить в `GOOGLE_SERVICE_ACCOUNT_JSON` (секрет: не пересылать в чатах).
3. Google Calendar → настройки своего календаря → «Открыть доступ» → email сервисного аккаунта → «Вносить изменения в мероприятия».
4. `GOOGLE_CALENDAR_ID` — email Даниила (ID календаря).

Ссылку Meet сервисный аккаунт в личном календаре создать не может, поэтому в событие ставится `MEET_URL`.

## Команды и кнопки для команды

- Карточка лида: «🙋 Беру сам» (ИИ и автоматика выключаются), «✉️ Написать через бота» (ответьте на сообщение бота — уйдёт лиду в его канал), «🚫 Не целевой».
- Запись: «✅ Подтвердить» — клиенту уходит подтверждение.
- `/leads` — последние 15 лидов со статусами.

## Тесты

```
pip install -r requirements.txt
python -m tests.test_sales
python -m tests.test_silence
python -m tests.test_voice
```

Telegram, WhatsApp, Google Calendar, Claude и ElevenLabs в тестах подменены. `test_voice` — голосовой ИИ: звонок, инструменты окон и записи, подпись вебхука, все итоги, повтор, сторож, ночь, «не звоните», выключенный флаг. Сценарий от заявки до звонка покрыт целиком: оба канала, шаблон, «позвонить вручную», календарь, напоминания, ответ через бота, окно 24 часа, отписка.
