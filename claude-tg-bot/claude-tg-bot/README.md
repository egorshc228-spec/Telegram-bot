# Telegram-бот на Claude

Бот только для Telegram: отвечает через Claude, ищет в интернете, анализирует фото и файлы,
помнит диалог и присылает результат в формате, который вы выбрали: **текст, Excel, Word,
PowerPoint, PDF или PNG**. Умеет конвертировать файлы между форматами.

## Быстрый старт

1. Токен у **@BotFather** в Telegram (`/newbot`).
2. API-ключ на console.anthropic.com и пополненный баланс (подписка Claude Pro/Free к API не относится).
3. Свой Telegram ID у **@userinfobot**.
4. Запуск:

```bash
cp .env.example .env        # впишите токен, ключ и свой ID в ALLOWED_USER_IDS
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

Через Docker (в образ уже входит LibreOffice): `docker compose up -d --build`

Для точного оформления при переводе Word, Excel и PowerPoint в PDF и PNG на машине должен быть
**LibreOffice** (`sudo apt install libreoffice`). Без него бот работает, но оформление упрощается
и предупреждает об этом.

Проверки без ключей: `python -m tests.test_smoke` и `python -m tests.test_convert`.
Те же проверки автоматически запускаются на GitHub при каждом изменении (`.github/workflows/tests.yml`).

## Где запускать: три пути

Цены ниже взяты из сторонних обзоров на октябрь 2026, перед выбором сверьте их на сайтах сервисов.
Оплата Claude API идёт отдельно, от хостинга она не зависит.

| | Путь | Цена | Сложность | Для чего |
|---|---|---|---|---|
| 1 | **Бесплатно или почти бесплатно**: свой компьютер или Oracle Cloud Always Free | 0 | средняя | проба, личное использование |
| 2 | **Самый эффективный**: VPS (например Hetzner) + Docker Compose | около 4–5 € в месяц | высокая | несколько ботов и клиентов, полный контроль |
| 3 | **Рекомендуемый**: GitHub + Railway | около 5 $ в месяц | низкая | быстрый старт без администрирования |

Общее для всех путей: бот работает в Docker-образе (Python внутри него), на вашей машине Python не нужен.
**Один токен бота = один запущенный экземпляр**: если бот запущен в двух местах, Telegram выдаёт ошибку конфликта.

### Путь 3. GitHub + Railway (рекомендуется для старта)

1. На github.com создайте **приватный** репозиторий и загрузите в него содержимое этой папки (`Dockerfile` в корне).
   Файл `.env` не загружайте никогда: ключи вводятся в Railway, а `.gitignore` защищает от случайной загрузки.
2. На railway.com войдите через GitHub: New Project → Deploy from GitHub repo → ваш репозиторий.
   Railway соберёт образ по `Dockerfile` (первая сборка несколько минут из-за LibreOffice).
3. Вкладка Variables: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `ALLOWED_USER_IDS` (по желанию `CLAUDE_MODEL`, `TAVILY_API_KEY`).
4. Добавьте к сервису **Volume** с путём `/srv/data`, иначе память диалогов (`bot.db`) стирается при каждом обновлении.
5. Домен создавать не нужно: бот сам опрашивает Telegram.
6. В логах должна появиться строка про запуск polling, затем напишите боту `/start`.
7. Обновления: изменили файл на GitHub, Railway пересобрал и перезапустил бота (проверьте, что автодеплой включён).

Railway считает деньги по использованию памяти и процессора, а LibreOffice при конвертации временно потребляет много.
Следите за расходами в панели.

### Путь 2. VPS + Docker Compose (максимум контроля и выгоды)

1. Закажите сервер Ubuntu 24.04 (у Hetzner план CX23: 2 vCPU, 4 ГБ памяти, около 4 € в месяц плюс IPv4).
2. Подключитесь по SSH, установите Docker: `curl -fsSL https://get.docker.com | sh`.
3. Загрузите код на сервер: `git clone` приватного репозитория (через deploy key) или `scp`.
4. `cp .env.example .env`, впишите ключи, затем `docker compose up -d --build`.
5. Обновление: `git pull && docker compose up -d --build`. Логи: `docker compose logs -f`.
6. Минимальная безопасность: вход по SSH-ключу, отключённый пароль, `ufw` с открытым только SSH, автообновления системы.
7. Дальше по мере роста: автодеплой из GitHub Actions по SSH, резервные копии `data/bot.db`, PostgreSQL вместо SQLite,
   мониторинг (например Uptime Kuma), отдельные боты для разных клиентов на одном сервере.

### Путь 1. Бесплатно

- **Свой компьютер или старый ноутбук:** установите Docker Desktop, затем `docker compose up -d --build`. Бот работает, пока компьютер включён и есть интернет.
- **Oracle Cloud Always Free:** бесплатная виртуальная машина, дальше те же шаги, что в пути 2. Условия нестабильны: по данным обзоров,
  в 2026 году бесплатный ARM-лимит урезан вдвое (до 2 vCPU и 12 ГБ), регистрация часто требует карту и бывает капризной,
  а простаивающие бесплатные машины Oracle может забирать. Хватит для проб, но не для клиентского бота.
- Бесплатные тарифы PaaS-сервисов быстро меняются или исчезают (у Fly.io, по обзорам, бесплатного тарифа уже нет), на них не стоит строить ничего важного.

## Как пользоваться

**Запрос.** Напишите вопрос или задачу. Бот спросит кнопками, в каком формате ответить.
Быстрее: начните сообщение с формата, например `/xlsx сравни цены на ноутбуки` или `/pptx тёмная тема, 6 слайдов про CRM`
(работают `/text /xlsx /docx /pptx /pdf /png`, а также `/excel /word /powerpoint`).

**Фото или файл с подписью.** Подпись становится заданием («сделай конспект», «вытащи таблицу»),
результат приходит в выбранном формате.

**Фото или файл без подписи.** Это конвертация: выберите формат, в который перенести.

**Принимаемые файлы:** docx, xlsx, csv, pptx, pdf, txt, png, jpg, webp (до 20 МБ, это лимит Telegram для ботов).

## Что в какой формат можно

| Формат ответа | Что принимает |
|---|---|
| **Excel** | Только таблицы: из CSV, Word, PowerPoint и PDF, в которых есть таблицы, и из фото таблицы. Фото без таблицы, рассказ, эссе и просьба прислать картинку отклоняются |
| **Word** | Любые запросы и любые файлы, включая презентации (текст слайдов и заметки переносятся) |
| **PowerPoint** | Любые запросы и файлы. Оформление задаётся словами: «тёмная тема», «акцентный цвет #D9480F», «шрифт Georgia» |
| **PDF** | Word, Excel, PowerPoint, изображения, текст, CSV, а также любые запросы |
| **PNG** | Изображения, Word, PDF, Excel, PowerPoint (каждая страница как скриншот, до 10 шт.), графики и страницы с текстом по запросу |

Если содержимое не подходит, бот отвечает: `❌ Недопустимый файл к вашему запросу: <причина>`.
Бот не умеет рисовать и искать фотографии, поэтому такие запросы в файловых форматах отклоняются.
Матрица правил лежит в `app/formats.py` (таблица `RULES`), меняйте её там.

## Структура

```
app/
├── main.py            запуск, меню команд, фоновая очистка
├── bot.py             Telegram: кнопки формата, приём фото и файлов, отправка результата
├── formats.py         правила допустимости «источник -> формат»
├── pending.py         запросы, ожидающие выбора формата
├── cleanup.py         удаление загрузок и результатов старше 24 часов
├── config.py          настройки из .env
├── docmodel.py        единая модель документа (текст, таблицы, картинки, слайды)
├── convert/
│   ├── __init__.py    конвертация: проверка правил -> чтение -> запись
│   ├── readers.py     docx, xlsx, csv, pptx, pdf, txt -> модель документа
│   ├── writers.py     модель документа -> xlsx, docx, pptx, pdf, png (темы презентаций)
│   └── render.py      LibreOffice (офис -> PDF) и pdfium (PDF -> PNG)
├── core/
│   ├── agent.py       цикл Claude с инструментами, отказ через reject_request
│   ├── memory.py      память диалога (SQLite, data/bot.db)
│   └── prompts.py     системный промпт и правила для каждого формата
├── tools/
│   ├── __init__.py    набор инструментов под выбранный формат
│   ├── files.py       make_file и reject_request
│   ├── web.py         fetch_url (с защитой от SSRF), поиск через Tavily
│   └── base.py        контекст запроса
└── media/images.py    подготовка фото для Claude
tests/                 test_smoke (агент, файлы, отказ), test_convert (матрица конвертаций)
```

## Как это работает

- Исследования в интернете: встроенный веб-поиск Claude либо Tavily (если задан `TAVILY_API_KEY`), плюс чтение страниц.
  Источники добавляются в файл отдельным разделом.
- Файловый формат выбирает пользователь, а не Claude. Claude получает только инструмент `make_file`
  под этот формат и `reject_request` для отказа.
- Чистая конвертация (файл без подписи) идёт без Claude и ничего не стоит. Исключение: фото в Excel,
  таблицу с картинки достаёт Claude.
- Скриншоты Word, Excel и PowerPoint делаются через LibreOffice: файл переводится в PDF, страницы рендерятся в PNG.
- Память хранит последние `MEMORY_MESSAGES` реплик на пользователя, `/reset` очищает её.

## Ограничения

- Сканы PDF без текста в Excel не конвертируются. Для Word, PowerPoint и PNG страницы анализирует Claude (первые 3).
- Из PDF таблицы извлекаются эвристически, сложная вёрстка может распознаться неточно.
- Переносятся текст, таблицы, картинки и заметки слайдов. Анимации, макросы, формулы Excel (сохраняются значения) и сложные
  стили не переносятся.
- Шрифты в PDF и PNG-карточках: DejaVu (кириллица есть, эмодзи нет). Пользовательские шрифты презентации должны быть у того,
  кто её открывает.
- Telegram: сообщение до 4096 символов (бот режет длинные), файл до 50 МБ на отправку и до 20 МБ на получение.
- Видео и аудио Claude напрямую не принимает.
- Альбом фото обрабатывается как отдельные сообщения.
- Всегда задавайте `ALLOWED_USER_IDS`: иначе бот открыт всем и расходует ваш баланс API.
- Для продакшена вместо polling лучше webhook, вместо SQLite PostgreSQL.
